# 고양이 소리 출처

실제 고양이 녹음 (위키미디어 공용). 잘라서 앞뒤 무음 제거, 150 Hz 아래·7 kHz 위 잡음 감쇠, 크기 맞춤(최대 0.45)만 했다. 골골송은 40~5000 Hz로 거르고 반복 이음매를 60 ms 겹쳤다.
상업용 앱에 쓸 수 있는 라이선스만 골랐다 (CC0, 퍼블릭 도메인, CC BY 4.0). 같은 조건 공유(SA) 라이선스는 쓰지 않았다.
