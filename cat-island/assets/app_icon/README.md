# 앱 아이콘 (등록용)

브랜드 상징 **'고양이 섬'**(원목 데크를 깐 작은 풀밭 섬 위에 정면을 보고 앉은 태비 고양이)을 맑은 하늘 위에 놓았다. 글자는 넣지 않는다. 브랜드 규칙: `docs/BRAND.md`.
그림은 게임 속 고양이 모델·재질·빛으로 Unity 에서 찍었다 (`unity/Assets/CatIsland/Tests/PlayMode/BrandArt.cs` → `prototype/3d/brand_make.py`, 2026-10-10).

| 파일 | 크기 | 형식 | 쓰는 곳 |
|---|---|---|---|
| `AppIcon-1024.png` | 1024×1024 | PNG, 투명 없음(RGB) | **앱스토어 제출 필수.** Xcode의 AppIcon(기본·밝은 모드)에 넣는다 |
| `AppIcon-1024-dark.png` | 1024×1024 | PNG, 배경 투명 | iOS 18 이상 어두운 모드 아이콘. 동그란 바다 판 위 심볼, 배경은 시스템이 어둡게 깔아 준다 |

**지킨 기준**
- 정사각형, 모서리를 직접 둥글게 깎지 않음 (애플이 자동으로 깎는다). 기본 아이콘은 투명 영역 없음.
- 섬과 고양이 얼굴이 가장자리에서 충분히 떨어져 있어 모서리가 잘려도 가려지지 않음(섬 폭 84%). 작은 크기에서도 귀·눈·줄무늬가 보인다.
- 아이콘 아래 이름은 **놀고섬** (홈 화면에 6~7글자만 보이므로 줄임말).
