# 앱 아이콘 (등록용)

브랜드 상징 **'식빵섬'**(식빵 자세로 잠든 고양이가 그대로 섬이 된 모양)을 하늘과 바다 위에 크게 놓았다. 글자는 넣지 않는다. 브랜드 규칙: `docs/BRAND.md`.
그림은 게임과 같은 3D 방식·같은 빛으로 만들었다 (`prototype/3d/brand_symbol.html`).

| 파일 | 크기 | 형식 | 쓰는 곳 |
|---|---|---|---|
| `AppIcon-1024.png` | 1024×1024 | PNG, 투명 없음(RGB) | **앱스토어 제출 필수.** Xcode의 AppIcon(기본·밝은 모드)에 넣는다 |
| `AppIcon-1024-dark.png` | 1024×1024 | PNG, 배경 투명 | iOS 18 이상 어두운 모드 아이콘. 동그란 바다 판 위 심볼, 배경은 시스템이 어둡게 깔아 준다 |
| `AppIcon-1024-tinted.png` | 1024×1024 | PNG, 흑백, 투명 없음 | iOS 18 이상 색조 모드 아이콘. 시스템이 사용자가 고른 색으로 물들인다 |
| `PlayStore-512.png` | 512×512 | PNG, 투명 없음 | 나중에 안드로이드(구글 플레이) 출시할 때 |
| `preview.png` | — | — | 홈 화면에서 둥근 모서리로 잘렸을 때의 모습 (밝은·어두운·색조, 큰 크기와 작은 크기) |

**지킨 기준**
- 정사각형, 모서리를 직접 둥글게 깎지 않음 (애플이 자동으로 깎는다). 기본 아이콘은 투명 영역 없음.
- 섬과 고양이 얼굴이 가장자리에서 충분히 떨어져 있어 모서리가 잘려도 가려지지 않음. 60px에서도 귀와 감은 눈이 보인다.
- 아이콘 아래 이름은 **놀고섬** (홈 화면에 6~7글자만 보이므로 줄임말).

**다시 만들기**: `docs/BRAND.md` 13장.
