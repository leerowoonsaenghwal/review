# 앱 아이콘 (등록용)

게임 속 3D 고양이(코리안 숏헤어, 앉은 자세)를 같은 빛과 그림자로 렌더링해 만들었다.

| 파일 | 크기 | 형식 | 쓰는 곳 |
|---|---|---|---|
| `AppIcon-1024.png` | 1024×1024 | PNG, 투명 없음(RGB) | **앱스토어 제출 필수.** Xcode의 AppIcon(기본·밝은 모드)에 넣는다 |
| `AppIcon-1024-dark.png` | 1024×1024 | PNG, 배경 투명 | iOS 18 이상 어두운 모드 아이콘 (선택). 배경은 시스템이 어둡게 깔아 준다 |
| `AppIcon-1024-tinted.png` | 1024×1024 | PNG, 흑백, 투명 없음 | iOS 18 이상 색조 모드 아이콘 (선택). 시스템이 사용자가 고른 색으로 물들인다 |
| `PlayStore-512.png` | 512×512 | PNG, 투명 없음 | 나중에 안드로이드(구글 플레이) 출시할 때 |
| `preview.png` | — | — | 홈 화면에서 둥근 모서리로 잘렸을 때의 모습 (밝은·어두운·색조, 큰 크기와 작은 크기) |

**지킨 기준**
- 정사각형, 모서리를 직접 둥글게 깎지 않음 (애플이 자동으로 깎는다).
- 기본 아이콘은 투명 영역 없음.
- 글자를 넣지 않음 (작은 크기에서 읽히지 않고, 앱 이름은 아이콘 아래에 따로 표시된다).
- 고양이 얼굴과 귀가 가장자리에서 충분히 떨어져 있어 모서리가 잘려도 가려지지 않음.
