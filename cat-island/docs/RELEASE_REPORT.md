## 4. 알고 있는 한계
- 그루밍: 새 그림체(큰 머리)에서 여러 품종의 세수(GroomFace)가 닿지 않아 빠짐. 게임은 그 품종에 있는 그루밍 동작(귀 긁기·발톱·입맛)으로 대신한다. 코리안 숏헤어·페르시안·히말라얀·친칠라·노르웨이 숲·엑조틱·벵갈·아메리칸 컬은 빠진 동작 없음. 10-09~10 세수 풀이 개선으로 8품종(재패니즈 밥테일·사바나·버먼·스코티시 폴드·스핑크스·셀커크렉스·맹크스·아비시니안)에 세수 추가, 남은 16품종 (DEV_LOG)
- 광고: 광고 회사 앱 ID 전까지 출시 빌드는 광고 없이 동작 (광고 버튼 숨김, 보상이 거저 나가지 않음)
- 성능은 에디터 수치. 아이폰 실기(특히 SE)에서 프레임·메모리를 사용자 테스트 때 확인
- 앱 347 MB(설치 후 크기, 10-10 빌드). 내려받기는 압축되어 약 145 MB(zip 측정)라 셀룰러 한도 200 MB 아래로 예상 — App Store Connect 앱 크기 보고서로 확인
