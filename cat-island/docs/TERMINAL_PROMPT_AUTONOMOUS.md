   - 플레이 시뮬레이션 테스트를 만들어 매번 돌려: 가상 시간으로 30일 플레이(하루 3회 접속, 방치 보상 최대 8시간, 손님 고양이, 산책, 텃밭, 출석, 계절 행사 날짜 넘김), 저장·불러오기·앱 강제 종료 후 복구, 기기 시계 되돌리기 방지, 재화 계산(코인·젤리 음수 없음, 밸런스 기준 GAME_PLAN 10장), 광고·결제는 테스트용 가짜 모듈로 성공·실패·취소 모두.

   - 성능: 아이폰 기준 60fps 목표, 메모리·그리기 횟수 측정해 기록. 넘치면 줄여.
