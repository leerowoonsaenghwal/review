# 고양이 용품 모델 (게임 에셋)

`assets/items/<이름>/`에 용품마다 Unity용 FBX와 glb, 색 텍스처, 노멀맵, 배치 정보(JSON)가 들어 있다.
모두 고양이와 같은 장난감 그림체로 만들었다. 이 게임의 고양이는 머리가 큰 장난감 비율이라 실제 고양이보다 크다(메인쿤 길이 약 1.1 m). 용품도 이 크기에 맞췄다.

## 고양이와 함께 놓는 법

좌표는 고양이 뼈대 기준(Root, 미터, +Z가 고양이 앞)이다. 각 용품 JSON의 `anchors`와 고양이 `clips.json`의 동작 정보에 값이 들어 있다.

- **그릇** (마시기 동작): 그릇 중심을 `Drink.drink.bowl`의 x, z에 놓는다.
  - 품종마다 몸을 숙이는 정도와 혀 길이가 계산되어 있다. 그래서 혀끝은 물(또는 사료) 표면 높이 3 cm에 닿고, 턱은 항상 표면보다 4 mm 위에 있다.
  - 그릇은 넓고 얕은 접시 모양이다. 큰 머리의 턱이 그릇 테두리에 걸리지 않게 하기 위해서다.
- **캣타워**: 판의 뒤쪽 끝을 `JumpUp.jump.deckBack`에 맞춰 놓는다(점프 시작 위치 기준).
  - 점프 거리 `jump.D`는 품종마다 다르다. 출발할 때 머리가 판에 걸리지 않을 만큼, 몸길이에 맞춰 계산했다.
  - 판 윗면 높이는 점프 높이(20 cm)와 같다. 착지한 뒤에는 판 윗면을 바닥으로 삼아 네 발이 그 위에 선다.
- **방석**: 방석 중심을 고양이 몸통 가운데 아래에 둔다. 고양이는 `anchors.top`만큼 올린다.
- **숨숨집**: 고양이 몸통 가운데가 숨숨집 중심보다 `anchors.catAhead`(20 cm) 앞에 오게 둔다. 고양이는 `anchors.floor`만큼 올린다. 몸은 안에, 머리는 문 밖에 둔다.
- **쥐돌이**: 앞발 치기 동작에서 발이 가장 낮게 내려오는 곳에 옆으로 돌려 놓는다. 꼬리가 고양이 발밑으로 들어가지 않게 하기 위해서다. 발은 장난감 윗면(6.1 cm)에서 멈추고, 돌아갈 때는 장난감 위로 넘어간다.

## 겹침 점검

`prototype/3d/qa_items.mjs`가 위 장면을 프레임마다 검사한다. 고양이의 모든 점(털, 얼굴, 혀, 발바닥 젤리)을 용품의 정확한 거리 함수로 잰다.

| 장면 | 기준 |
|---|---|
| 그릇에서 마시기 | 고양이의 어느 곳도 그릇 안으로 3 mm 넘게 들어가지 않는다. 매번 할짝일 때 혀가 표면에 3 mm 안으로 닿는다. |
| 캣타워 점프 | 오르는 내내 캣타워 안으로 3 mm 넘게 들어가지 않는다. |
| 방석 | 푹신한 천이라 15 mm까지 눌리는 것은 허용한다. |
| 숨숨집 | 12 mm까지 허용한다. |
| 쥐돌이 치기 | 발이 장난감에 닿고, 12 mm 넘게 파고들지 않는다. |

## 그림자

- **모든 용품은 구멍 없이 닫힌 한 덩어리다.** 내보낸 뒤 모든 모서리가 정확히 두 면에 붙어 있는지 확인했다(열린 모서리 0, 겹친 모서리 0). 틈으로 빛이 새거나 그림자가 끊기는 일이 없다.
- **움푹한 곳의 그늘은 텍스처에 구워 넣었다.** 그릇 안쪽, 캣타워 판 아래, 숨숨집 안이 해당한다. 가장 가벼운 모바일 셰이더에서도 입체감이 산다.
- **Unity 설정 (URP 기준)**

| 항목 | 값 | 이유 |
|---|---|---|
| 해 (Directional Light) 그림자 | Soft Shadows | 동물의 숲 같은 부드러운 그림자 |
| Shadow Resolution | 2048 | |
| Shadow Distance | 6~10 m | 섬 한 화면. 짧을수록 선명하다. |
| Depth Bias / Normal Bias | 0.3 / 0.4 부근에서 시작 | 둥근 표면의 줄무늬 그림자를 없애면서, 발밑 그림자가 떨어져 보이지 않는 값 |
| 고양이·용품 Mesh Renderer | Cast Shadows On, Receive Shadows On | 머리가 앞발에, 캣타워 판이 기둥에 그림자를 드리운다 |
| Renderer Feature | Screen Space Ambient Occlusion | 발과 바닥, 몸과 방석이 맞닿는 곳이 자연스럽게 어두워진다 |

미리보기(`prototype/3d/items.html`, `scene_items.html`)도 같은 원칙으로 설정했다. 그림자 카메라를 장면에 꼭 맞추고, 작은 법선 오프셋과 아주 작은 깊이 오프셋을 쓴다.

## 만드는 법

```
node prototype/3d/export_items.mjs …   # (export_items.py가 부름) 고해상도 원본 + 배치 정보
python3 prototype/3d/export_items.py OUT_DIR [id,...]
```

1. `items.js`: 둥근 기본 도형을 더하고 깎아 조형한 뒤, 표면을 하나의 닫힌 메시로 뽑는다(고양이와 같은 방식).
2. `blender_items.py`: 다시 감싸기(voxel remesh) → 면 줄이기 → 구멍 메우기 → 펼치기(UV) → 색·노멀·그늘 굽기 → FBX/glb로 내보낸다.
