## 1. 왜 새로 만들었나

### 1-1. 이전 이름·로고·아이콘의 아쉬운 점
| 문제 | 내용 |
|---|---|
| 이름이 겹친다 | 'Cat Island - Relaxing Game', 'The Secret of Cat Island', 'NyankoIsland' 등 **같거나 비슷한 이름의 고양이 섬 게임이 이미 있다.** 검색해도 묻히고, 흔한 낱말이라 상표 등록도 어렵다. |
| 우리만의 모양이 없다 | 아이콘이 '섬 위의 3D 고양이 렌더링'일 뿐이라, 다른 고양이 게임과 나란히 놓으면 구별되지 않는다. 작게 줄이면 무엇인지 흐려진다. |
| 글자에 개성이 없다 | 무료 글꼴을 그대로 부풀린 글자라 누구나 비슷하게 만들 수 있다. 나무색 테두리는 빵집처럼 보였다. |
| 체계가 없다 | 색, 글꼴, 말투, 쓰임새별 규칙이 없어 화면·스토어·홍보물이 제각각이 될 위험. |

### 1-2. 새 이름을 고른 기준
1. **동물의 숲처럼 권하는 말 + 장소.** 쉽고 바로 이해된다. ('모여봐요 동물의 숲' → '모동숲')
2. **줄임말이 자연스럽다.** '놀고섬'은 '놀고 싶은 섬'처럼 뜻으로도 읽힌다.
3. **세 나라에서 같은 느낌.** 한국어 '놀러와요', 일본어 'あそびにきてね', 영어 'Come Play' 모두 친구를 부르는 말.
4. **겹치지 않는다.** 2026-10-05 검색 기준 같은 제목·같은 줄임말의 게임 없음 (14장: 상표 확인은 출시 전 필수).
5. **우리 약속과 맞는다.** "벌주지 않는다, 돌아오면 반겨 준다" → 언제든 '놀러와요'.

## 2. 브랜드 핵심

### 2-1. 브랜드 한 문장
**"언제 와도 반겨 주는, 고양이가 사는 작은 섬"**

### 2-2. 우리가 주는 것 (약속)
| 약속 | 이용자가 느끼는 것 | 브랜드에서 보이는 방식 |
|---|---|---|
| 벌주지 않는다 | 며칠 만에 와도 미안하지 않다 | 말투는 늘 반가움. "왔구나!" 재촉·죄책감 문구 없음 |
| 고양이가 주인공 | 내 고양이가 거기 산다 | 모든 그림의 중심은 고양이. 숫자·버튼은 가장자리 |
| 매일 조금씩 다르다 | 오늘은 무엇이 있을까 | 계절·시간대마다 바뀌는 상징과 화면 (9-4) |
| 사진은 기기 안에만 | 안심 | "사진은 내 휴대폰 밖으로 나가지 않아요"를 숨기지 않고 말한다 |

### 2-3. 브랜드 이야기 (세계관 한 토막)
> 아주 먼 옛날, 바다 한가운데서 햇볕을 쬐던 커다란 고양이가 식빵 자세로 잠이 들었습니다.
> 너무 오래 자는 바람에 등에는 풀이 자라고, 귀에는 꽃이 피고, 동그란 얼굴 아래로는 모래사장이 생겼어요.
> 그렇게 생긴 섬에 하나둘 고양이들이 놀러 오기 시작했습니다. 오늘은 당신 차례예요. **놀러와요, 고양이섬!**

- 이 이야기가 상징(고양이 섬)의 이유다. 첫 실행 화면, 스토어 설명, 홍보 영상 첫 장면에 쓴다.
- 게임 속 섬의 모양을 이 이야기와 맞출지(섬 전체가 잠든 고양이 모양)는 **기획 결정 사항**이다. 정하기 전에는 상징과 홍보에서만 쓴다.

### 2-4. 성격 (사람이라면)
| 성격 | 이렇게 | 이렇게는 안 |
|---|---|---|
| 포근함 | 햇볕, 낮잠, 담요 같은 말과 그림 | 차갑고 반짝이는 금속 느낌 |
| 느긋함 | 기다려 주는 말투, 여백 많은 화면 | "지금 당장!", 깜빡이는 경고, 시간 압박 |
| 장난스러움 | 고양이 귀가 달린 글자, 말장난 조금 | 유치한 말투, 아기 말, 과한 감탄사 |
| 다정함 | 이용자를 친구처럼 부름 | 명령, 훈계, 비교 |
| 정직함 | 확률·광고·사진 처리를 솔직하게 | 숨긴 조건, 과장 광고 |

### 2-5. 키워드
햇볕 · 낮잠 · 식빵 자세 · 둥글둥글 · 장난감 같은 섬 · 다정한 초대

## 3. 이름 체계

### 3-1. 표기
| 쓰임 | 한국어 | 일본어 | 영어 |
|---|---|---|---|
| 정식 (스토어 이름) | 놀러와요 고양이섬 | あそびにきてね ねこの島 | Come Play, Cat Isle |
| 줄임 (말, SNS) | 놀고섬 | あそねこ | Cat Isle |
| 스토어 부제 | 고양이와 사는 작은 섬 | ねこと暮らす小さな島 | A cozy island life with cats |
| 해시태그 | #놀고섬 #놀러와요고양이섬 | #あそねこ | #CatIsle |
| **홈 화면 아이콘 아래 이름** | **놀고섬** | **あそねこ** | **Cat Isle** |

- **'고양이섬'은 붙여 쓴다.** ('고양이 섬' ×) 정식 이름 가운데는 한 칸 띄운다: '놀러와요 고양이섬'.
- 홈 화면에는 6~7글자만 보이므로 아이콘 아래 이름은 줄임말로 한다 (Unity `PlayerSettings.productName`, iOS 표시 이름).
- 문장 속에서는 줄임말 '놀고섬'을 쓸 수 있다. 처음 나올 때는 정식 이름을 먼저 쓴다.
- 영어는 쉼표를 포함한 'Come Play, Cat Isle'이 정식. 'Cat Island'로 쓰지 않는다 (겹치는 게임이 있음).

### 3-2. 게임 속 이름 (같은 말투로)
| 대상 | 이름 | 비고 |
|---|---|---|
| 무지개다리를 건넌 고양이 공간 | **별나라** | '죽음' 같은 말 대신 |
| 일반 재화 / 고급 재화 | **코인 / 젤리** | 젤리 = 고양이 발바닥 젤리 |
| 하루 1마리 찾아오는 고양이 | **손님 고양이** | |
| 고양이가 모아 둔 보상 | **선물 바구니** | '방치 보상'은 문서용 말 |
| 출석 | **도장** | 계절 행사는 '계절 도장판' |
| 이용자 | **집사님** | 말풍선에서 고양이가 부르는 말 |

### 4-5. 하지 말 것

- 고양이 귀(양의 ㅇ)나 새싹(섬)을 빼기 — 우리 글자의 표시다.
- 그림자·외곽선·반짝이 효과 덧붙이기 (로고 안에 이미 부드러운 그림자가 있다).
- 보호 여백 안에 다른 글자 넣기, 심볼과 워드마크 사이 간격 임의로 바꾸기.
- 고양이를 다른 표정(화남·놀람)으로 바꾸기.

## 5. 심볼 '고양이 섬' (2026-10-10 새로)

이전 '식빵섬'(빛바랜 연두색 덩어리)은 지금 게임 그래픽(맑은 풀색, 큰 머리의 동글한 고양이, 나무 데크, 크림·코코아 UI)과 맞지 않아 바꿨다.

### 5-1. 요소와 뜻
| 부분 | 뜻 |
|---|---|
| 작은 풀밭 섬 (흙 옆면이 보이는 장난감 섬) | 이용자의 섬. 게임과 같은 풀밭 무늬 |
| 원목 데크 2 x 2 칸 | 섬을 내 마음대로 꾸민다 (데크 타일) |
| 정면을 보고 앉은 코리안 숏헤어 태비 | 주인공 고양이. 게임 속 모델 그대로 |
| 노랑·빨강 튤립, 동그란 덤불 | 섬의 계절과 생기 |
| 맑은 하늘과 구름 (아이콘만) | 언제 와도 맑은 섬 |

### 5-2. 모양 규칙
- **게임 화면과 같은 그림이어야 한다**: 게임의 고양이 모델·재질·빛으로 찍는다(따로 그리지 않는다).
- 작아져도 '귀 달린 동그란 얼굴 + 둥근 섬'으로 읽힌다. 고양이 얼굴이 아이콘 폭의 약 1/3.
- 보는 각도: 살짝 위(18°)에서 정면.

### 5-3. 만드는 방법
- Unity `Tests/PlayMode/BrandArt.cs`(평소 테스트에서 돌지 않음)가 배경 없이 2048 px 로 찍고, `prototype/3d/brand_make.py` 가 아이콘·변형·워드마크·조합을 만든다. 13장 명령.

## 6. 워드마크 (2026-10-10 새로)

### 6-1. 구조
```
 (놀러와요)        ← 딸기우유 둥근 배지 + 크림 글자 (게임의 분홍 버튼)
 고 양 이 섬^^      ← 크림 글자 + 굵은 코코아 테두리 + 아래로 떨어진 그림자, '섬' 위에 고양이 귀 둘
```
- 글꼴은 게임 제목·버튼과 같은 **주아(Jua)**. 게임 화면의 버튼·숫자판과 같은 크림 + 코코아 테두리라 화면 어디에 놓아도 같은 말투로 보인다.
- 두 줄 크기 비율: '놀러와요' 배지 글자 = '고양이섬' 글자의 약 37%.

### 6-2. 우리 글자만의 표시
1. **'섬' 위의 고양이 귀 둘** (분홍 속귀) — 섬이 곧 고양이.
2. 딸기우유 배지 '놀러와요' — 반겨 주는 말.

### 6-3. 줄임 워드마크
- '놀고섬': 같은 크림 + 코코아 테두리 글자 (`wordmark_short.png`).

## 9. 그래픽 요소

### 9-1. 모양
- **둥근 카드**: 모든 창·버튼. 모서리 반지름 16pt 이상, 버튼은 높이의 1/2 (알약 모양).
- **꼬리표**: 워드마크의 분홍 꼬리표 모양. 새 소식, 행사 이름, '한정' 표시에 쓴다.
- **물결 띠**: 화면 위·아래 경계를 부드러운 물결로 (섬과 바다).
- **새싹**: 새로 생긴 것, 처음 해 보는 것 표시.

### 9-2. 아이콘
- 두꺼운 둥근 선(2pt, 끝 둥글게) + 단색 채움. 색은 코코아, 선택되면 잔디·딸기우유.
- 소재: 고양이 발바닥, 생선, 털실, 그릇, 조개, 새싹. 사람 손·칼 같은 날카로운 소재는 쓰지 않는다.
- 크기 24pt 격자, 안쪽 여백 2pt.

### 9-3. 3D 그림
- 게임과 같은 규칙: 해 1개 + 하늘빛, 부드러운 그림자, 무광 재질, 위에서 비스듬한 시점 (`docs/ART_STYLE.md`).
- 홍보 그림의 고양이는 게임의 실제 3D 고양이를 쓴다 (따로 그린 고양이 금지 → 기대와 실제가 같게).

### 9-4. 계절·시간대 변형 (매일 조금씩 다르다)
- 심볼에만 작은 장식을 바꿔 단다. 모양·색표는 그대로.

| 때 | 심볼 장식 |
|---|---|
| 봄 | 등에 벚꽃 나무 (야자수 대신) |
| 여름 | 튜브, 수박 |
| 가을 | 단풍, 호박 |
| 겨울 | 눈 덮인 등, 목도리 |
| 밤·별나라 | 남색 바다, 등 위에 작은 별 |

- 앱 아이콘은 계절마다 바꾸지 않는다 (알아보기 쉬움이 먼저). 바꾸고 싶으면 이용자가 고르는 '대체 아이콘'으로.

## 10. 말투 (보이스)

### 10-1. 원칙
1. **친구를 부르듯.** 해요체. 짧게. 문장 끝에 고양이 말투('~냥')는 쓰지 않는다 (금방 질린다). 고양이의 말은 말풍선 그림으로.
2. **반가움이 먼저.** 오랜만에 와도 "왔구나!" 재촉·죄책감 없음.
3. **정직하게.** 광고, 확률, 결제, 사진 처리는 숨기지 않고 쉬운 말로.
4. **별나라는 조용히.** 느낌표 없이, 짧고 따뜻하게.

### 10-2. 예시
| 상황 | 이렇게 | 이렇게는 안 |
|---|---|---|
| 접속 | 왔구나! 코코가 선물을 모아 뒀어요. | 3일 동안 접속하지 않았습니다. |
| 알림 | 산책 간 코코가 돌아왔어요. 뭘 물고 왔을까요? | 지금 접속하지 않으면 보상이 사라집니다! |
| 광고 보상 | 짧은 광고를 보면 선물이 두 배가 돼요. | 무료!!! 지금 바로 받기!!! |
| 결제 | 젤리 100개 · 1,200원 | 단 하루! 마지막 기회! |
| 확률 | 이 상자의 확률은 여기서 모두 볼 수 있어요. | (확률을 숨기거나 작게) |
| 사진 | 사진은 집사님 휴대폰 안에서만 써요. 밖으로 나가지 않아요. | (설명 없음) |
| 별나라 | 코코가 별나라에서 편히 쉬고 있어요. | 코코가 사망했습니다. |
| 실패·오류 | 앗, 잠깐 길을 잃었어요. 다시 해 볼까요? | 오류가 발생했습니다 (코드 1043) |

## 11. 적용

### 11-1. 앱 아이콘 (`assets/app_icon/`)
- 고양이 섬 심볼을 맑은 하늘 위에 크게. 글자 없음.
- iOS 18 어두운 모드: 배경 투명, 동그란 바다 판 위 심볼. 색조 모드: 흑백.
- 규격과 파일은 `assets/app_icon/README.md`.

### 11-2. 게임 첫 화면 (`assets/brand/mock_title_screen.png`)
- 위: 워드마크, 가운데 아래: 3D 고양이 섬, 아래: "화면을 눌러 시작해요" (크림 알약 + 코코아 글자).
- 시간대에 따라 하늘색과 심볼 장식이 바뀐다 (9-4).

### 11-3. 스토어
- 이름: 정식 이름. 부제: 3-1 표.
- 스크린샷 5장 순서: ① 첫 화면(로고) ② 내 사진으로 고양이 만들기 ③ 쓰다듬기·골골송 ④ 섬 꾸미기 ⑤ 손님 고양이·도감.
- 스크린샷 글자: 위쪽 크림 띠 + 코코아 글자 한 줄 (예: "내 고양이를 사진 한 장으로").

### 11-4. SNS·홍보
- 프로필: 줄임 워드마크 또는 3D 심볼 (동그랗게 잘림 → 심볼만).
- 영상: 끝 화면에 가로 조합 + "놀러와요!" 고양이 울음 효과음.

### 11-5. 굿즈 아이디어 (나중에)
- 식빵섬 말랑 인형·쿠션 (심볼 그대로), 발바닥 젤리 키링, 단색 심볼 자수 에코백, '놀러와요' 꼬리표 스티커.
