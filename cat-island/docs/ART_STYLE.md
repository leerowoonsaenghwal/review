# 디자인 스타일 기획

> 고양이, 용품, 섬, 화면(버튼·창)이 모두 한 그림체로 보이게 하는 기준이다. 새 그림이나 모델을 만들 때 이 문서의 기준에 맞는지 먼저 확인한다.

## 1. 한 문장
**"햇볕 드는 오후, 장난감 같은 섬에서 사는 동그란 고양이들."**

키워드: 포근함 · 장난감 같음 · 둥글둥글 · 따뜻한 색 · 조용한 생활감

## 2. 기준이 되는 원칙
| 원칙 | 내용 |
|---|---|
| 둥글게 | 모서리가 뾰족한 물체가 없다. 모든 모서리는 둥글린다 (작은 용품 최소 반지름 5 mm, 가구 1~2 cm). |
| 크게 단순하게 | 작은 무늬나 잔 장식보다 큰 덩어리로 알아보게 한다. 멀리서 실루엣만 봐도 무엇인지 알 수 있어야 한다. |
| 장난감 비율 | 고양이는 머리가 크고(몸의 약 60%) 다리가 짧다. 모든 고양이가 같은 크기·같은 뼈대 (먼치킨만 짧은 다리). |
| 질감은 부드럽게 | 반짝이는 금속, 거울 같은 반사 없음. 모든 재질은 무광(천, 나무, 도자기, 털). |
| 그림자는 부드럽게 | 해 하나 + 부드러운 그림자 + 움푹한 곳의 은은한 그늘. 검은 그림자 없음. |

## 3. 고양이
- **비율**: 머리 크게, 몸 짧고 통통하게, 다리 짧게. 눈은 크고 둥글게 (품종에 따라 아몬드형).
- **품종 표현** (크기·뼈대는 모두 같고, 아래로만 구분한다)
  - 얼굴: 납작한 얼굴(페르시안), 뾰족한 얼굴(샴·오리엔탈), 둥근 볼(브리티시)
  - 귀: 접힌 귀(스코티시 폴드), 말린 귀(아메리칸 컬), 큰 귀(스핑크스·데본 렉스), 귀 끝 털(메인쿤)
  - 털: 짧은 털, 긴 털(목 갈기, 꼬리 털), 곱슬 털, 털 없음
  - 꼬리: 짧은 꼬리(재패니즈 밥테일, 맹크스), 풍성한 꼬리
  - 몸 두께: ±10% 안에서만 (브리티시 약간 통통, 오리엔탈 약간 날씬)
  - 무늬와 색: 고등어, 클래식 태비, 포인트, 삼색, 턱시도 등
- **표정**: 눈 깜빡임, 입 벌림 두 가지 표정 변형. 화난 표정·이빨 드러내기는 쓰지 않는다.
- **움직임**: 살짝 통통 튀는 느낌. 착지할 때 몸이 아주 조금 눌렸다 펴진다. 귀와 꼬리는 몸보다 한 박자 늦게 따라온다.

## 4. 색

### 4-1. 기본 색표
| 이름 | 색 | 쓰는 곳 |
|---|---|---|
| 크림 | `#fbf6e6` | 화면 배경, 카드 바탕 |
| 밀크티 | `#f6f1e3` | 두 번째 바탕 |
| 코코아 | `#6f5a40` | 글자 (검정 대신) |
| 라떼 | `#a08a6a` | 보조 글자 |
| 잔디 | `#b6dd8f` | 섬 땅 |
| 하늘 | `#c7e3f2` | 하늘, 카펫, 시원한 강조 |
| 버터 | `#f9cf7a` | 나무 테두리, 노란 강조 |
| 딸기우유 | `#ff7f9f` | 주요 버튼, 알림 점, 하트 |
| 복숭아 | `#f2a7a0` | 그릇, 부드러운 강조 |

- **검정(#000)과 순수 흰색(#fff)은 쓰지 않는다.** 가장 어두운 색은 코코아, 가장 밝은 색은 크림.
- 채도는 중간 이하. 형광색 없음.

### 4-2. 하루 시간대 (실제 시간을 따른다)
| 시간 | 해 색 | 하늘 | 느낌 |
|---|---|---|---|
| 아침 (6~10시) | 연한 복숭아 | 연한 하늘 + 분홍 | 상쾌함 |
| 낮 (10~17시) | 따뜻한 흰색 `#fff4dc` | 맑은 하늘 | 기본 |
| 저녁 (17~20시) | 주황 | 주황 → 보라 | 노을 |
| 밤 (20~6시) | 푸른 달빛 | 남색 + 별 | 고양이는 잠, 창문 불빛 |

### 4-3. 별나라
- 남색 `#2b3266` → 보라 `#6b5b9a` 밤하늘, 구름은 연보라 `#d9d2f0`, 별빛은 버터색.
- 섬보다 어둡지만 무섭지 않게. 은은하게 빛나는 효과만.

## 5. 재질과 조명 (게임 화면 설정)
- **재질**: 모두 무광. 털은 아주 약한 결 반사만 (러시안 블루 같은 은빛 털만 약간).
- **그늘**: 그릇 안, 캣타워 판 밑, 숨숨집 안처럼 움푹한 곳의 그늘은 텍스처에 미리 구워 넣었다 (가벼운 휴대폰에서도 입체감 유지).
- **조명**: 해 1개(부드러운 그림자) + 하늘빛(위는 푸르스름, 아래는 잔디의 반사색).
- **그림자**: 부드러운 그림자, 해상도 2048, 거리 6~10 m. 발밑에서 그림자가 떨어져 보이지 않게 설정한다 (자세한 값은 [ITEMS.md](ITEMS.md)).
- **화면 효과**: 아주 약한 색 보정(따뜻하게), 접촉 그늘 효과(SSAO). 번짐(블룸)은 별나라와 밤 불빛에만.

## 6. 카메라
- 위에서 비스듬히 내려다보는 시점 (약 35~45도). 좁은 화각(약 28도)이라 장난감 상자를 들여다보는 느낌.
- 손가락으로 돌리기는 좌우 90도까지만, 확대·축소 2단계.
- 사진 모드에서만 자유 시점 + 고양이 눈높이.

## 7. 화면(UI)
- **글꼴**: 둥근 손글씨 느낌의 한글 글꼴 (시안은 Jua. 무료 공개 글꼴). 숫자는 같은 글꼴.
- **모양**: 모든 창과 버튼은 둥근 카드 (모서리 반지름 16 pt 이상). 그림자는 아주 연하게.
- **버튼 크기**: 최소 44 pt (손가락으로 누르기 편하게). 주요 버튼은 딸기우유색, 보조는 크림색 + 코코아 테두리.
- **아이콘**: 두꺼운 둥근 선 + 단색 채움. 고양이 발바닥, 생선, 털실 같은 고양이 소재를 쓴다.
- **화면을 가리지 않기**: 고양이가 주인공이므로 화면 위아래 띠 안에만 버튼을 둔다. 가운데 70%는 섬.
- **말풍선**: 고양이의 상태·요청·튜토리얼은 모두 머리 위 작은 말풍선 아이콘으로.
- **배너 광고 없음** (화면 분위기를 지키기 위해).

## 8. 소리
- 잔잔한 어쿠스틱 (우쿨렐레, 마림바, 오르골). 시간대마다 편곡이 바뀐다.
- 효과음: 골골송, 짧은 야옹, 발소리(용품 재질별), 코인은 작은 방울 소리.
- 쓰다듬을 때 골골송에 맞춘 약한 진동.

## 9. 성능 기준 (아이폰 11 이상에서 초당 60장)
| 항목 | 기준 |
|---|---|
| 고양이 1마리 | 삼각형 약 24,500개 (몸 14,000 + 얼굴 10,500), 텍스처 2048 |
| 용품 1개 | 삼각형 800~6,000개, 텍스처 512~2048 |
| 한 화면 | 고양이 최대 6마리 + 용품 40개 |
| 그림자를 드리우는 물체 | 고양이와 큰 용품만 (작은 소품은 그늘 텍스처로 대신) |

## 10. 만들 때 하면 안 되는 것
- 뾰족한 모서리, 날카로운 이빨이나 발톱 강조
- 사실적인 털 한 올 한 올 표현 (장난감 그림체가 깨짐)
- 검은 외곽선, 진한 그림자
- 고양이와 크기 비율이 안 맞는 용품 (모든 용품은 고양이 크기에 맞춰 만든다. [ITEMS.md](ITEMS.md))
- 다른 게임과 똑같은 모양이나 이름 (동물의 숲은 분위기 참고만 하고, 모양과 캐릭터는 우리 것으로)
