# 놀러와요 고양이섬 — 게임 기획서 (전체)

> 동물의 숲 같은 그림체로 고양이를 키우는 아이폰용 방치형 게임 **놀러와요 고양이섬**(줄임말 놀고섬)의 전체 기획이다. 이름·로고·색·말투는 `BRAND.md`. 게임 기획, 수익 기획, 디자인 스타일을 한 문서에 담았다.

**목차**
1. 게임 기획 — 무엇을 하고, 왜 매일 다시 들어오는가
2. 수익 기획 — 광고와 결제
3. 디자인 스타일 — 어떻게 보이고 들리는가
4. 만드는 조건

---

## 1부. 게임 기획

### 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 장르 | 방치형 고양이 키우기 + 섬 꾸미기 (동물의 숲 같은 편안한 게임) |
| 기기 | 아이폰 (세로 화면, 한 손 조작) |
| 주 이용자 | 고양이를 키우거나 좋아하는 20~40대. 편안한 게임을 즐기는 사람. 한국·일본·미국 |
| 한 번 접속 | 3~5분 |
| 하루 접속 | 2~4번 (아침, 점심, 잠들기 전) |
| 핵심 감정 | "내 고양이가 저기서 살고 있다", 위로, 모으는 즐거움, 꾸미는 즐거움 |

**세 가지 약속** (모든 기획 판단의 기준)
1. **벌주지 않는다.** 며칠 안 들어와도 고양이가 아프거나 떠나지 않는다. 돌아오면 반겨 준다.
2. **고양이가 주인공이다.** 숫자보다 고양이의 행동이 먼저 보인다. 보상도 고양이의 행동으로 준다.
3. **매일 조금씩 다르다.** 오늘만 오는 손님 고양이, 오늘만 피는 꽃, 오늘의 선물이 있다.

### 2. 반복 구조 (얼마나 자주 무엇을 하는가)

```
[30초]  쓰다듬기 → 고양이가 골골송·몸 비비기·배 보이기로 반응
[5분]   방치 보상 받기 → 밥·물 채우기 → 놀아 주기 → 오늘 할 일 확인 → 용품 사서 놓기
[하루]  오늘 할 일 3개 · 손님 고양이 1마리 · 산책 선물 · 출석 도장
[일주일] 주간 목표 · 주말 장터(특별 상점)
[한 달]  계절 행사 · 새 용품 묶음
[길게]  품종 도감 33종 · 섬 넓히기 · 고양이 성장 기록 · 별나라
```

#### 2-1. 30초 반복: 만지는 맛
- 화면을 문지르면 쓰다듬기. 고양이마다 좋아하는 곳이 다르다 (턱 밑, 이마, 엉덩이). 싫어하는 곳(배)을 오래 만지면 살짝 깨문다(아프지 않은 귀여운 반응).
- 반응: 눈 감기, 골골송(진동 + 소리), 꼬리 세우기, 머리 비비기, 배 보이기.
- 하루 첫 쓰다듬기는 호감도 보너스.

#### 2-2. 5분 반복: 돌보고 꾸미기
1. **방치 보상 받기**: 고양이들이 모아 둔 코인 (최대 8시간). 광고를 보면 2배.
2. **돌봄**: 상태가 낮은 고양이에게 밥·물·놀이. 상태 아이콘은 고양이 머리 위 작은 말풍선으로만 보인다.
3. **할 일 확인**: 오늘 할 일 3개 중 남은 것.
4. **상점 / 꾸미기**: 코인으로 용품을 사서 놓는다. 고양이가 바로 그 용품을 써 본다(새 동작이 보상).

#### 2-3. 하루 반복
| 콘텐츠 | 내용 | 다시 올 이유 |
|---|---|---|
| 오늘 할 일 3개 | "고양이 2마리 쓰다듬기", "캣타워에서 사진 찍기" 등. 다 하면 젤리 소량 | 매일 바뀜 |
| 손님 고양이 | 하루 1마리, 무작위 품종의 길고양이가 섬에 들른다. 간식을 주면 도감에 등록, 3번 만나면 입양 가능 | **품종 수집의 핵심 동력** |
| 산책 | 고양이를 산책 보내면 1~8시간 뒤 선물(재료, 코인, 가끔 희귀 용품)을 물고 돌아온다 | 돌아올 시간에 알림 |
| 텃밭 | 캣닢·밀싹·꽃을 심고 실제 시간으로 자란다 (4~12시간) | 수확 시간 |
| 출석 도장 | 7일 주기. 7일째 상자 | 연속 접속 |
| 광고 선물 | 고양이가 가끔 물어오는 선물 상자 (하루 2회) | 보상형 광고 |

#### 2-4. 일주일 반복
- **주간 목표**: 할 일 15개 달성 → 주간 상자 (희귀 용품 조각).
- **주말 장터**: 토·일에만 여는 떠돌이 상인 고양이. 희귀 용품, 다른 지역 용품.
- **고양이 일기 주간 정리**: 이번 주 찍힌 사진과 일어난 일을 그림일기처럼 보여 준다 (공유 가능).

#### 2-5. 한 달 · 계절 반복
| 달 | 행사 | 한정 용품 예시 |
|---|---|---|
| 1월 | 설날 | 한복 목도리, 떡국 그릇 |
| 2월 | 2월 22일 일본 고양이의 날 | 고양이 신사, 오뎅 |
| 4월 | 벚꽃 | 벚꽃 캣타워, 꽃잎 방석 |
| 6~8월 | 여름 / 8월 8일 세계 고양이의 날 | 수박 방석, 튜브, 축하 케이크 |
| 9월 | 9월 9일 한국 고양이의 날 | 한옥 숨숨집 |
| 10월 | 할로윈 | 호박 숨숨집, 망토 |
| 12월 | 겨울 | 눈사람, 털실 공, 크리스마스 트리 |

- 섬 날씨와 낮·밤은 **실제 시간과 계절**을 따른다 (밤에는 고양이가 잔다, 겨울엔 눈).
- 계절 행사 도장판: 행사 기간 동안 할 일을 하면 도장이 쌓이고, 다 모으면 그 계절 한정 용품을 받는다 (무료).

#### 2-6. 길게 보는 목표
1. **품종 도감 33종**: 손님 고양이로 만나서 채운다. 무늬 도감(털 무늬 12종)은 따로.
2. **섬 넓히기**: 집 안 → 마당 → 바닷가 → 꽃 언덕 → 등대. 구역마다 다리를 놓는다(코인 + 재료).
3. **고양이 성장 기록**: 함께한 날 수, 사진 앨범, 처음 한 일(첫 캣타워 점프 등).
4. **호감도 10단계**: 단계마다 새 동작, 별명 짓기, 특별 포즈 해금.
5. **용품 도감**: 출시 때 60종 → 매달 10종 이상 추가.

### 3. 고양이 시스템

#### 3-1. 상태 (5가지)
| 상태 | 낮아지는 속도 | 채우는 방법 | 낮을 때 |
|---|---|---|---|
| 배고픔 | 8시간에 바닥 | 사료·캔·츄르 | 그릇 앞에서 기다림 (울지 않음) |
| 목마름 | 10시간 | 물·우유 | 물그릇 앞에 앉음 |
| 놀이 | 12시간 | 장난감, 쓰다듬기 | 혼자 꼬리 쫓기 |
| 청결 | 하루 | 화장실 청소, 빗질 | 털이 살짝 부스스해 보임 |
| 기분 | 위 4개의 평균 | — | 동작이 느려짐 |

- **바닥이어도 아프지 않고, 떠나지 않는다.** 대신 방치 보상이 줄어든다(최대 −50%). 벌이 아니라 "돌봐 주면 더 좋다"는 방향.
- 상태가 모두 높으면 "행복" 표시 → 방치 보상 +20%.

#### 3-2. 성격 (5종)
고양이마다 하나. 좋아하는 용품, 자주 하는 동작, 말풍선 아이콘이 다르다.

| 성격 | 좋아하는 것 | 자주 하는 동작 |
|---|---|---|
| 느긋함 | 방석, 숨숨집 | 식빵 자세, 잠자기 |
| 장난꾸러기 | 쥐돌이, 낚싯대, 공 | 앞발 장난, 달리기 |
| 새침함 | 캣타워 꼭대기 | 그루밍, 높은 곳에서 내려다보기 |
| 먹보 | 츄르, 캔 | 그릇 앞 대기, 입술 핥기 |
| 겁쟁이 | 숨숨집, 박스 | 숨기, 손님 고양이 피하기 |

#### 3-3. 혼자 사는 고양이 (자율 행동)
- 고양이는 상태와 성격에 따라 스스로 용품을 고른다. 이용자가 보고 있지 않아도 섬은 계속 산다.
- 고양이끼리: 같이 자기, 서로 그루밍, 쫓기 놀이, 같은 방석 차지하기.
- 이 장면들이 **사진 모드**의 재료가 된다.

#### 3-4. 호감도
- 쓰다듬기, 밥, 놀이, 선물로 오른다. 10단계.
- 3단계: 이름 부르면 돌아봄 / 5단계: 별명 / 7단계: 이용자 쪽으로 와서 배 보이기 / 10단계: 특별 사진 프레임.

---


### 4. 내 고양이 만들기 (사진으로)

1. 사진 1장을 고른다. **사진은 기기 밖으로 나가지 않는다** (기기 안에서 처리).
2. 털 색·무늬·눈 색·귀 모양을 읽어 가장 가까운 품종과 무늬를 고른다.
3. 이용자가 직접 고칠 수 있다: 무늬, 색, 눈 색, **눈 모양(진한 눈 / 색 눈 / 테두리 눈), 수염(짧은 / 긴 / 수염 점)**, 꼬리 길이, 털 길이. 눈 모양과 수염은 사진을 보고 가장 비슷한 것을 먼저 골라 준다.
4. 모든 고양이는 같은 크기·같은 뼈대라 (먼치킨만 짧은 다리) 사진 고양이도 모든 동작과 모든 용품을 그대로 쓴다.
5. 첫 고양이는 무료. 추가 칸은 젤리로 연다.

### 5. 별나라 (무지개다리를 건넌 고양이)

**원칙: 이곳은 장사하는 곳이 아니다.**
- 광고 없음. 상태·배고픔 없음. 알림 없음(이용자가 켠 기념일 알림만).
- 판매하는 것은 별나라 꾸미기 용품뿐이며, 무료로도 충분히 꾸밀 수 있다.

**구성**
- 밤하늘 아래 작은 구름 섬. 고양이 한 마리마다 별 하나.
- 사진, 이름, 함께한 날, 좋아하던 것을 적는 **추억 카드**.
- **편지 쓰기**: 쓴 편지는 별똥별이 되어 날아간다 (기기에만 저장).
- 별나라 고양이는 사진으로 만든 모습 그대로 구름 위에서 편히 잔다. 쓰다듬으면 골골송.
- 생일·만난 날 같은 기념일에, 이용자가 원하면 섬 밤하늘에 별똥별이 지나간다.

**말투와 연출**
- "죽음", "사망"이라는 말은 쓰지 않는다. "별나라로 떠난", "별이 된"을 쓴다.
- 밝고 따뜻한 밤 색 (보라·남색 + 은은한 빛). 슬픈 음악 대신 잔잔한 오르골.
- 처음 들어갈 때 한 번만 안내 문구를 띄운다. 이용자가 원할 때만 찾아오는 공간.

### 6. 섬과 꾸미기

- **격자 배치**: 용품을 칸에 놓는다. 고양이가 쓰는 자리(그릇 앞, 캣타워 착지점)는 자동으로 비워 둔다 → 겹침이 생기지 않는다.
- **테마 세트**: 같은 테마 용품 3개 이상 → 방치 보상 +5% (최대 +15%).
- **섬 구역**: 집 안, 마당, 바닷가, 꽃 언덕, 등대. 구역마다 어울리는 손님 고양이와 재료가 다르다.
- **만들기(제작)**: 산책·텃밭 재료로 용품을 만든다. 레시피는 손님 고양이와 산책 선물로 얻는다. 코인 외에 "시간과 정성"으로 얻는 길을 열어, 결제하지 않는 이용자도 계속 할 일이 있다.

### 7. 처음 7일 (신규 이용자 설계)

| 날 | 목표 | 받는 것 |
|---|---|---|
| 1일 (첫 10분) | 첫 고양이 만들기(사진 또는 품종 선택) → 밥 주기 → 쓰다듬기 → 방석 놓기 → 고양이가 방석에서 잠 | 방석, 그릇, 장난감 |
| 1일 (두 번째 접속) | 방치 보상 받기, 첫 손님 고양이 | 코인, 손님 도감 1 |
| 2일 | 산책 보내기, 텃밭 심기 | 첫 선물 |
| 3일 | 캣타워 얻기 → 첫 점프 장면 | 캣타워 |
| 4일 | 첫 만들기(제작) | 레시피 |
| 5일 | 두 번째 고양이 입양 (손님 고양이 3회 만남) | 두 번째 고양이 |
| 6일 | 섬 첫 확장 (마당) | 새 구역 |
| 7일 | 출석 7일 상자, 사진 모드 첫 공유 | 희귀 용품 |

- 처음 3일 동안은 전면 광고 없음 (수익 기획서와 같음).
- 튜토리얼 문구는 고양이 말풍선으로만. 화면을 가리는 긴 설명은 없다.

### 8. 알림 (기기 안 알림, 서버 없음)

- 하루 최대 2번. 기본은 "방치 보상 가득"과 "산책 귀가"만 켜짐.
- 문구는 고양이 시점: "코코가 선물을 물고 왔어요" (명령조·죄책감 유발 문구 금지).
- 밤 10시 ~ 아침 8시에는 보내지 않는다.

### 10. 재화와 경제

| 재화 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 코인 | 방치 보상, 할 일, 손님 고양이, 광고 | 기본 용품, 사료, 섬 확장 |
| 젤리 | 결제, 할 일(소량), 출석, 광고(하루 1회 소량), 계절 행사 | 한정 용품, 고양이 칸, 꾸미기 |
| 재료 | 산책, 텃밭, 손님 고양이 | 만들기 |

**밸런스 기준**
- 기본 용품 1개 = 하루 접속 1번 분량의 코인.
- 섬 확장 1단계 = 약 1주일 분량.
- 결제 없이도 한 달에 한정 용품 1~2개는 얻을 수 있게 젤리를 푼다.
- 확률 상자는 확률을 모두 공개한다 (법적 의무).

## 2부. 수익 기획

목표는 **월 순수익 500만원**이다. 수익은 두 갈래다.
1. **보상형 광고**: 이용자가 스스로 광고를 보고 보상을 받는다. 수익의 중심이다.
2. **인앱 결제**: 젤리, 한정 용품, 계절 세트, 별나라 꾸미기를 판다.

용품(사료, 장난감, 캣타워 등)은 두 수익을 이어 주는 고리다. 고양이를 돌보려면 용품이 필요하고, 용품은 코인으로 사며, 코인은 방치 보상과 광고로 빨리 모인다.

> 이 장의 숫자(광고 단가, 전환율 등)는 업계 공개 자료를 바탕으로 한 추정치다. 출시 전 소규모 시험 출시에서 실제 값으로 바꿔 넣는다.

### 1. 게임 한 바퀴 (매일 반복되는 흐름)

```
접속 → 방치 보상 받기 (코인) → 밥 주기 · 놀아 주기 · 쓰다듬기 (호감도 상승)
     → 코인으로 용품 사기 · 섬 꾸미기 → 고양이가 새 용품으로 새 동작을 보여 줌
     → 호감도 단계 달성 → 새 고양이 입양 (사진으로 만들기) → 다시 처음으로
```

- **방치 보상**은 앱을 꺼 둔 동안 고양이가 모은 코인이다. 최대 8시간까지 쌓인다. 하루 2~3번 접속할 이유가 된다.
- **용품을 놓으면 고양이가 그 용품으로 동작한다.** 이것이 "사고 싶게 만드는" 핵심이다. 아래 표처럼 지금 만든 동작을 그대로 쓴다.

| 용품 | 고양이 동작 | 효과 |
|---|---|---|
| 사료 그릇 · 캔 · 츄르 | 먹기 (우유 마시기 동작의 핥기·턱 움직임 재사용) | 배고픔 회복, 호감도 |
| 물그릇 · 정수기 | 우유 마시기, 물 건드리기 (앞발 장난) | 목마름 회복 |
| 낚싯대 · 공 · 쥐돌이 | 앞발 장난, 뛰기, 점프 | 놀이 욕구 회복, 큰 호감도 |
| 캣타워 (1~3단) | 점프해 오르기, 식빵 자세, 잠자기 | 방치 보상 +10~30% |
| 스크래처 | 기지개 (앞발 뻗기) | 기분 유지 |
| 방석 · 숨숨집 | 식빵 자세, 잠들기, 잠자기 | 휴식 회복, 방치 보상 시간 연장 |
| 화장실 | (전용 동작 추가 예정) | 청결 유지 |

---


### 2. 재화

| 재화 | 얻는 방법 | 쓰는 곳 |
|---|---|---|
| **코인** (일반) | 방치 보상, 돌보기, 광고 | 기본 용품, 사료 |
| **젤리** (고급) | 결제, 출석, 광고(하루 1회 소량) | 한정 용품, 꾸미기, 새 고양이 칸 |

젤리를 광고로 아주 조금 얻을 수 있게 하는 이유가 있다. 결제하지 않는 이용자도 "언젠가는 받을 수 있다"고 느껴야 오래 남는다.

---


### 3. 광고 배치 원칙

**보상형 광고를 중심으로 한다.** 이용자가 원할 때만 본다. 그래서 불만이 적고 단가가 가장 높다.

| 위치 | 보상 | 하루 상한 |
|---|---|---|
| 방치 보상 받을 때 | 보상 2배 | 3회 |
| 사료가 떨어졌을 때 | 사료 1회분 무료 | 2회 |
| 상점 무료 뽑기 | 용품 상자 1개 | 3회 |
| 고양이가 선물을 물어 옴 (무작위) | 선물 열기 (코인 · 젤리 소량) | 2회 |
| 외출한 고양이 빨리 부르기 | 대기 시간 즉시 끝 | 2회 |

**전면 광고**(화면 전체를 가리는 광고)는 최소로 쓴다.
- 처음 설치하고 3일 동안은 보여 주지 않는다.
- 이후에도 화면이 넘어갈 때만, 최소 4분 간격으로, 하루 최대 6회까지만 보여 준다.
- 한 번이라도 결제한 이용자에게는 보여 주지 않는다.

**배너 광고는 쓰지 않는다.** 동물의 숲 같은 그림체에서 화면 아래 배너는 분위기를 크게 해치고 수익도 작다.

**별나라(무지개다리를 건넌 고양이 공간)에는 어떤 광고도 넣지 않는다.** 슬픔을 이용한 수익화로 보이면 평판이 무너진다. 별나라의 꾸미기 용품만 판매한다.

### 4. 결제 상품

| 상품 | 가격 (안) | 내용 |
|---|---|---|
| 젤리 묶음 | 1,200 ~ 59,000원 | 젤리 |
| 계절 한정 세트 | 9,900원 | 벚꽃 · 여름 · 할로윈 · 겨울 캣타워와 방석 |
| 별나라 꾸미기 | 3,900원 ~ | 별나라 전용 장식 (광고 없음) |

한국은 **확률형 아이템의 확률 공개가 법적 의무**다(게임산업진흥법, 2024년 3월 시행). 무료 뽑기를 포함해 모든 상자의 확률을 상점 화면에 표시한다.

### 5. 수익 계산 (추정)

**가정 (기본안)**

| 항목 | 값 | 설명 |
|---|---|---|
| 보상형 광고 단가 | 1,000회당 15,000원 | 한국 · 미국 iPhone 기준 추정 (국가별로 차이 큼) |
| 1인당 하루 보상형 시청 | 4회 | 상한 12회 중 |
| 전면 광고 단가 | 1,000회당 8,000원 | |
| 1인당 하루 전면 광고 | 1.5회 | 3일 이후, 결제자 제외 |
| 결제 전환율 | 월 2% | 방치형 게임 평균 수준 |
| 결제자 1인당 월 결제 | 10,000원 | |
| 애플 수수료 | 15% | 소규모 사업자 프로그램 (연 매출 100만 달러 이하) |

**1일 이용자 1명이 하루에 버는 돈**

| 출처 | 계산 | 금액 |
|---|---|---|
| 보상형 광고 | 4회 × 15원 | 60원 |
| 전면 광고 | 1.5회 × 8원 | 12원 |
| 결제 (수수료 뺀 뒤) | 2% × 10,000원 × 0.85 ÷ 30일 | 약 6원 |
| **합계** | | **약 78원 / 일** |

한 명이 한 달에 약 2,300원을 번다. 광고 수익은 광고 회사 몫을 뺀 뒤의 금액이라 앱스토어 수수료가 붙지 않는다.

**필요한 하루 이용자 수**

| 시나리오 | 이용자 1명당 월 수익 | 월 마케팅비 | 필요 하루 이용자 |
|---|---|---|---|
| 보수 (광고 단가 −40%, 전환 1%) | 약 1,300원 | 100만원 | **약 4,600명** |
| 기본 | 약 2,300원 | 100만원 | **약 2,600명** |
| 낙관 (광고 6회, 전환 3%) | 약 3,300원 | 100만원 | **약 1,800명** |

즉 **매일 2,000~5,000명이 접속하면** 목표에 닿는다. 세금은 별도다.
방치형 게임은 이용자가 하루 2~3번 짧게 들어오는 구조라 이 규모가 현실적이다. 단, 첫날 다시 들어오는 비율 40% 이상, 7일째 15% 이상을 유지해야 한다.

### 6. 서버 없이 만드는 방법

처음 조건(서버 없음, API 키 없음)을 지킨다.
- **광고**: AdMob 또는 AppLovin MAX를 앱에 넣는다. 광고 회사 서버와 앱이 직접 통신하므로 우리 서버가 필요 없다. 보상 지급도 앱 안에서 처리한다.
- **결제**: StoreKit 2를 쓴다. 기기 안에서 영수증을 검증하므로 서버가 필요 없다.
- **저장**: 기기 저장 + iCloud 백업을 쓴다.
- **방치 보상 시간 조작 방지**: 기기 시계를 되돌리면 마지막 저장 시각과 비교해 막는다. 보상은 최대 8시간으로 제한해 조작의 이득을 줄인다.
- **사진으로 고양이 만들기**: 기기 안에서 처리한다.

**출시 전 필수 사항**
- 앱 추적 동의 팝업(ATT). 동의하지 않아도 광고는 나오지만 단가가 낮아진다.
- 연령 등급 12세 이상으로 설정한다. 아동용으로 분류되면 맞춤 광고를 쓸 수 없다.
- 앱 안의 디지털 재화는 반드시 인앱 결제로 판다 (애플 심사 지침 3.1.1).
- 개인정보 처리방침 페이지를 마련한다. 정적 웹페이지면 충분하다.

---


### 7. 출시 순서와 확인할 지표

1. **소규모 시험 출시**: 캐나다나 호주 등 한 나라에서 2~4주 동안 운영한다. 확인할 지표:
   - 첫날 다시 들어오는 비율 40%
   - 7일째 다시 들어오는 비율 15%
   - 하루 보상형 광고 시청 3회 이상
2. 숫자가 나오면 이 장의 가정을 실제 값으로 바꾸고 광고 상한과 보상량을 조정한다.
3. **정식 출시**: 한국, 일본, 미국. 일본은 고양이 게임 수요가 크고 광고 단가도 높다.
4. 계절 한정 용품을 3개월마다 추가해 다시 돌아올 이유를 만든다.

### 3. 고양이
- **비율**: 머리 크게, 몸 짧고 통통하게, 다리 짧게. 눈은 크고 둥글게 (품종에 따라 아몬드형).
- **품종 표현** (크기·뼈대는 모두 같고, 아래로만 구분한다)
  - 얼굴: 납작한 얼굴(페르시안), 뾰족한 얼굴(샴·오리엔탈), 둥근 볼(브리티시)
  - 귀: 접힌 귀(스코티시 폴드), 말린 귀(아메리칸 컬), 큰 귀(스핑크스·데본 렉스), 귀 끝 털(메인쿤)
  - 털: 짧은 털, 긴 털(목 갈기, 꼬리 털), 곱슬 털, 털 없음
  - 꼬리: 짧은 꼬리(재패니즈 밥테일, 맹크스), 풍성한 꼬리
  - 몸 두께: ±10% 안에서만 (브리티시 약간 통통, 오리엔탈 약간 날씬)
  - 무늬와 색: 고등어, 클래식 태비, 포인트, 삼색, 턱시도 등
- **표정**: 눈 깜빡임, 입 벌림 두 가지 표정 변형. 화난 표정·이빨 드러내기는 쓰지 않는다.
- **움직임**: 살짝 통통 튀는 느낌. 착지할 때 몸이 아주 조금 눌렸다 펴진다. 귀와 꼬리는 몸보다 한 박자 늦게 따라온다.

#### 4-3. 별나라
- 남색 `#2b3266` → 보라 `#6b5b9a` 밤하늘, 구름은 연보라 `#d9d2f0`, 별빛은 버터색.
- 섬보다 어둡지만 무섭지 않게. 은은하게 빛나는 효과만.


### 5. 재질과 조명 (게임 화면 설정)
- **재질**: 모두 무광. 털은 아주 약한 결 반사만 (러시안 블루 같은 은빛 털만 약간).
- **그늘**: 그릇 안, 캣타워 판 밑, 숨숨집 안처럼 움푹한 곳의 그늘은 텍스처에 미리 구워 넣었다 (가벼운 휴대폰에서도 입체감 유지).
- **조명**: 해 1개(부드러운 그림자) + 하늘빛(위는 푸르스름, 아래는 잔디의 반사색).
- **그림자**: 부드러운 그림자, 해상도 2048, 거리 6~10 m. 발밑에서 그림자가 떨어져 보이지 않게 설정한다.
- **화면 효과**: 아주 약한 색 보정(따뜻하게), 접촉 그늘 효과(SSAO). 번짐(블룸)은 별나라와 밤 불빛에만.


### 6. 카메라
- 위에서 비스듬히 내려다보는 시점 (약 35~45도). 좁은 화각(약 28도)이라 장난감 상자를 들여다보는 느낌.
- 손가락으로 돌리기는 좌우 90도까지만, 확대·축소 2단계.
- 사진 모드에서만 자유 시점 + 고양이 눈높이.


### 7. 화면(UI)
- **글꼴**: 둥근 손글씨 느낌의 한글 글꼴 (시안은 Jua. 무료 공개 글꼴). 숫자는 같은 글꼴.
- **모양**: 모든 창과 버튼은 둥근 카드 (모서리 반지름 16 pt 이상). 그림자는 아주 연하게.
- **버튼 크기**: 최소 44 pt (손가락으로 누르기 편하게). 주요 버튼은 딸기우유색, 보조는 크림색 + 코코아 테두리.
- **아이콘**: 두꺼운 둥근 선 + 단색 채움. 고양이 발바닥, 생선, 털실 같은 고양이 소재를 쓴다.
- **화면을 가리지 않기**: 고양이가 주인공이므로 화면 위아래 띠 안에만 버튼을 둔다. 가운데 70%는 섬.
- **말풍선**: 고양이의 상태·요청·튜토리얼은 모두 머리 위 작은 말풍선 아이콘으로.
- **배너 광고 없음** (화면 분위기를 지키기 위해).


### 8. 소리
- 잔잔한 어쿠스틱 (우쿨렐레, 마림바, 오르골). 시간대마다 편곡이 바뀐다.
- 효과음: 골골송, 짧은 야옹, 발소리(용품 재질별), 코인은 작은 방울 소리.
- 쓰다듬을 때 골골송에 맞춘 약한 진동.


### 9. 만들 때 하면 안 되는 것
- 뾰족한 모서리, 날카로운 이빨이나 발톱 강조
- 사실적인 털 한 올 한 올 표현 (장난감 그림체가 깨짐)
- 검은 외곽선, 진한 그림자
- 고양이와 크기 비율이 안 맞는 용품 (모든 용품은 고양이 크기에 맞춰 만든다)
- 다른 게임과 똑같은 모양이나 이름 (동물의 숲은 분위기 참고만 하고, 모양과 캐릭터는 우리 것으로)

## 4부. 만드는 조건

- **기기**: 아이폰 (세로 화면, 한 손 조작). 나중에 안드로이드로 넓힐 수 있게 Unity로 만든다.
- **서버 없음**: 저장은 기기 + iCloud, 업적·순위는 Game Center, 결제는 기기 안 검증, 광고는 광고 회사와 앱이 직접 통신.
- **사진 처리**: 사진으로 고양이를 만드는 처리는 모두 기기 안에서. 사진은 밖으로 나가지 않는다.
- **고양이 모양**: 모든 고양이는 같은 크기·같은 뼈대 (먼치킨만 짧은 다리). 품종 특징은 얼굴, 귀, 눈, 털, 꼬리, 무늬, 약간의 몸 두께(±10%)로 낸다. 그래서 모든 고양이가 모든 동작과 모든 용품을 똑같이 쓴다.
- **품질**: 출시할 수 있는 수준. 고양이와 용품이 겹치거나 깨져 보이지 않고, 그림자가 자연스러워야 한다.
