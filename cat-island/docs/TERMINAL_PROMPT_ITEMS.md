# 터미널 추가 지시문: A단계 용품 디테일 (지시문 5단계를 바꾸는 내용)

```
용품 작업(앞 지시문의 5단계)은 새로 확정된 기준으로 해 줘. 시작 전에 브랜치 최신 내용을 받아 와.

기준: cat-island/docs/ART_DIRECTION.md 5장 (시안 그림 docs/images/items_detail_sample.png, docs/images/cat_towers_sample.png)
시안 코드: cat-island/prototype/3d/items_detail.html (방석·사료 그릇·캣타워 1단과 캣타워 부품 KIT, 캣타워 5종)

할 일:
1. 용품 13종을 5-1(디테일 기준)과 5-2(용품별 적용표)대로 다시 만들어 줘: 각이 살아 있는 둥근 모양, 그린 듯한 질감(천·나뭇결·유약·밧줄·카펫), 작은 부품 2~4개, 색 바꾸기 2~3종. 방석·사료 그릇·캣타워 1단은 시안 그대로.
2. 캣타워 5종(1단 스툴형, 2단 계단형, 3단 하우스형, 3단 나무형, 5단 높은 타워)을 5-3대로 게임 파일로 만들어 줘. 판 높이 0.4 m 단위.
3. 크기와 고양이가 쓰는 높이(BOWL_SURF, TOY_TOP, 방석 윗면, 숨숨집 바닥)는 바꾸지 마. 부품 하나하나 닫힌 메시로(그림자). 다시 내보낸 뒤 qa_items.mjs로 점검.
4. 지금 점프(JumpUp)는 0.2 m만 오르니, 새 캣타워 5종은 파일만 만들고 게임에는 아직 넣지 마 (0.4 m 점프와 뛰어내리기는 다음 B단계에서 만든다). 게임에서는 지금의 낮은 1단을 계속 써.
5. 방석이 고양이가 누우면 눌리는 것, 공이 구르는 것 같은 반응은 모양만 준비해 두고(눌림 모양 등), 움직임 연결은 C단계에서 한다.
6. 단계마다 한국어로 짧게 보고하고 커밋해 줘. 시안과 다르게 바꿔야 하면 먼저 물어봐.
```
