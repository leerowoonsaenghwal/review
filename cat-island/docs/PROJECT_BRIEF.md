## 1. 어떤 앱인가

**동물의 숲 같은 그림체로 고양이를 키우는 아이폰용 방치형 게임.** Unity로 만든다.

- **핵심 기능 1 — 내 고양이 만들기**: 키우는 고양이 사진으로 닮은 3D 고양이를 만든다 (기기 안 처리, 사진은 밖으로 나가지 않음). 33품종 기본 제공.
- **핵심 기능 2 — 별나라**: 세상을 떠난 고양이를 기억하는 추모 공간. **광고 없음**, 꾸미기 용품만 판매.
- **세 가지 약속**: ① 벌주지 않는다(고양이가 아프거나 떠나지 않음) ② 고양이가 주인공 ③ 매일 조금씩 다르다.

**33품종**: 코리안 숏헤어, 러시안 블루, 페르시안, 히말라얀, 친칠라 페르시안, 샴, 스코티시 폴드, 브리티시 숏헤어, 먼치킨, 랙돌, 버먼, 아메리칸 숏헤어, 노르웨이 숲, 메인쿤, 시베리안, 벵갈, 이집션 마우, 아비시니안, 소말리, 사바나, 오리엔탈, 스핑크스, 터키시 앙고라, 터키시 반, 엑조틱 숏헤어, 아메리칸 컬, 데본 렉스, 코니시 렉스, 셀커크 렉스, 라팜, 맹크스, 재패니즈 밥테일, 봄베이.

## 2. 게임 기획 요약 → [GAME_DESIGN.md](GAME_DESIGN.md)
- 한 번 3~5분, 하루 2~4번 접속.
- 반복 구조: 쓰다듬기(30초) → 돌봄·꾸미기(5분) → 오늘 할 일·손님 고양이·산책·텃밭(하루) → 주간 목표·주말 장터(주) → 계절 행사(달) → 품종 도감·섬 넓히기·호감도 10단계(길게).
- **손님 고양이**: 하루 1마리 무작위 품종이 찾아옴 → 간식 주면 도감 등록 → 3번 만나면 입양. 품종 수집의 핵심.
- 고양이 상태 5가지(배고픔, 목마름, 놀이, 청결, 기분). 바닥이어도 아프지 않고 방치 보상만 줄어든다.
- 성격 5종(느긋함, 장난꾸러기, 새침함, 먹보, 겁쟁이) → 좋아하는 용품과 자주 하는 동작이 다름.
- 서버 없이 함께하기: Game Center(업적·순위), 사진 공유, QR로 고양이 카드 교환(친구 섬에 손님으로 방문).
- 처음 7일 설계, 알림 하루 최대 2번(밤 10시~아침 8시 금지), 확인할 지표(첫날 40%, 7일 15%, 30일 6%).

## 3. 수익 요약 → [BUSINESS_PLAN.md](BUSINESS_PLAN.md)
- 목표: 월 순수익 500만원. 하루 이용자 2,000~5,000명이면 도달(추정).
- **보상형 광고 중심** (방치 보상 2배, 사료 무료, 무료 뽑기, 선물 상자, 외출 즉시 귀가). 전면 광고는 최소(처음 3일 없음, 4분 간격, 하루 6회, 결제자 제외). **배너 없음.**
- 결제: 젤리 묶음, 계절 세트, 별나라 꾸미기. (광고 제거와 월간 패스는 팔지 않는다.)
- 재화: 코인(일반), 젤리(고급), 재료(제작용). 확률 상자 확률 공개(법적 의무).
- 연령 12세 이상, 추적 동의 팝업, 개인정보 처리방침 정적 페이지.

## 4. 디자인 스타일 요약 → [ART_STYLE.md](ART_STYLE.md)

## 5. 엔진 → [ENGINE.md](ENGINE.md)
- **Unity 6 + URP로 결정.** 이유: 광고(AdMob, AppLovin MAX)·결제 공식 도구가 가장 안정적, 우리 FBX가 바로 들어감, 연 매출 20만 달러 미만 무료.
- 웹 시안(three.js, `prototype/3d`)은 **제작 도구**로 계속 쓴다: 모델·동작 계산·겹침 점검 → FBX/glb 내보내기.

## 6. 지금까지 만든 것

### 6-1. 고양이 게임 모델 → [GAME_MODEL.md](GAME_MODEL.md)
- 이음새 없는 하나의 몸 메시 + 얼굴 메시(눈·코·입·혀·수염·발바닥 젤리), 뼈대, 표정 변형 2개(깜빡임, 입 벌림), 혀 뼈 5개.
- 몸 14,000 삼각형 + 얼굴 약 10,500, 털 텍스처 2048, 노멀맵 1024. FBX + glb.
- 동작 21종: 서 있기, 걷기, 빠르게 걷기, 달리기, 점프해 오르기, 앉기·앉아 있기·일어나기, 눕기, 식빵 자세, 잠자기, 잠들기, 얼굴 씻기, 귀 긁기, 발톱 다듬기, 기지개, 마시기, 입술 핥기, 발라당·발라당 있기, 앞발 장난.
- 품종마다 몸에 맞지 않아 겹치는 동작은 자동으로 빼고, 빠진 이유와 대신 재생할 동작을 `clips.json`의 `skippedClips`에 적는다.
- 파일: `assets/cats/<품종>.glb / .fbx / .clips.json` (33종 모두 있음).

### 6-2. 용품 13종 → [ITEMS.md](ITEMS.md)
사료·물·우유 그릇, 캔, 츄르, 공, 쥐돌이, 낚싯대, 스크래처, 방석, 숨숨집, 화장실, 캣타워 1단. 모두 구멍 없는 닫힌 메시, 그늘을 텍스처에 구움. 파일: `assets/items/<이름>/`.
- 고양이가 쓰는 자리(그릇 위치, 캣타워 판 위치, 방석·숨숨집 위치, 쥐돌이 위치와 방향)는 품종별 `clips.json`에 들어 있다.

### 6-3. 자동 점검
- `prototype/3d/qa.mjs`: 모든 동작을 프레임마다 실제 스킨 메시로 검사(다리가 몸에 4 mm 넘게 박힘, 바닥 뚫림, 혀·발이 닿아야 할 때 3 mm 이내).
- `prototype/3d/qa_items.mjs`: 고양이 + 용품 장면 검사(그릇 마시기, 캣타워 점프, 방석, 숨숨집, 쥐돌이 치기). 결과는 `docs/qa_items/`.

### 6-4. 기획 문서
`docs/GAME_DESIGN.md`, `docs/ART_STYLE.md`, `docs/ENGINE.md`, `docs/BUSINESS_PLAN.md`, `docs/ITEMS.md`, `docs/GAME_MODEL.md`, `docs/CAT_CATALOG.md`(품종·무늬 조사, 사진→고양이 설계).

## 9. 만드는 방법 (명령)

```bash
cd cat-island/prototype/3d && npm install          # three 0.169
python3 -m http.server 8766 &                       # 시안 페이지와 내보내기에 필요
# 고양이 1종 만들기 (30분~4시간)
python3 export_cats.py OUT/raw <품종>
python3 blender_finish.py OUT/raw/<품종>_raw.glb OUT/final/<품종> <품종>
# 점검
node qa.mjs <품종>                  # 동작 겹침
node qa_items.mjs <품종>            # 용품과 함께
# 용품
python3 export_items.py OUT_DIR [이름,...]
```
필요한 것: Node, Python 3, `bpy==4.2.0`(Blender를 파이썬 모듈로), `playwright==1.49.1`.
