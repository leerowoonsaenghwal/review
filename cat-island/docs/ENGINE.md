# 엔진 검토: Unity가 최선인가

결론부터: **Unity 6 (URP)를 그대로 쓴다.** 이 게임의 수익과 제작 방식에 가장 잘 맞는다. 아래는 다른 선택지와 비교한 근거다. (2026년 10월 기준)

## 1. 이 게임에 필요한 것
1. 아이폰에서 부드러운 3D (고양이 여러 마리 + 그림자 + 털 질감)
2. **보상형 광고 연결** (수익의 중심) — AdMob, AppLovin MAX 같은 광고 중개 도구
3. 인앱 결제, iCloud 저장, Game Center
4. 우리가 만든 고양이·용품 파일(FBX / glb, 뼈대, 표정 변형, 동작 21개)을 그대로 쓰기
5. 혼자 또는 작은 팀이 오래 운영하기 쉬울 것
6. 사진으로 고양이 만들기 (기기 안 처리)

## 2. 후보 비교

**확인한 사실**
- Unity Personal(무료)은 연 매출·투자 20만 달러 미만이면 쓸 수 있고, 시작 화면의 Unity 로고도 의무가 아니다. 우리 목표(월 순수익 500만원 ≈ 연 4~5만 달러)는 이 범위 안이다. ([Unity Personal](https://unity.com/products/unity-personal), [MCV/DEVELOP](https://mcvuk.com/?p=62419))
- 애플은 2025년에 SceneKit을 사실상 더 개발하지 않기로(심각한 오류 수정만) 하고 RealityKit으로 옮기라고 안내했다. 애플 기본 도구로 간다면 RealityKit뿐인데, 게임 편집기가 없어 섬 꾸미기 같은 게임을 만들기엔 손이 많이 간다. ([Apple 문서](https://developer.apple.com/documentation/realitykit/bringing-your-scenekit-projects-to-realitykit), [WWDC25 세션](https://developer.apple.com/videos/play/wwdc2025/288?time=303))
- Godot용 AppLovin MAX 공식 도구는 있지만, Godot 4.5에서 아이폰 빌드가 안 된다는 보고가 있다. 광고가 수익의 중심인 우리에게는 위험하다. ([AppLovin-MAX-Godot](https://github.com/AppLovin/AppLovin-MAX-Godot), [Godot 포럼](https://forum.godotengine.org/t/godot-4-5-ios-export-gives-undefined-symbols-errors-in-xcode-due-to-not-updated-plugin/125054))

## 3. 결정과 이유
**Unity 6 + URP(가벼운 그래픽 설정)**
1. **수익과 직결되는 광고·결제 도구가 가장 안정적이다.** 광고 수익이 중심인 게임에서 가장 중요한 기준.
2. 우리 고양이·용품 파일이 이미 Unity용으로 맞춰져 있다 (FBX, 축 방향, 뼈대 설정, 그림자 설정 문서).
3. **모든 고양이가 같은 뼈대**가 되었으므로 Unity에서 동작 묶음 하나(Animator)를 모든 고양이가 같이 쓸 수 있다. 품종마다 다른 부분만 덮어쓰면 된다.
4. 무료 범위 안이고, 나중에 안드로이드 출시도 쉽다.

**다른 선택이 나은 경우**
- 광고 없이 유료 앱으로 판다면 → Godot도 충분하다.
- 아이폰·아이패드·비전 프로 전용 고급 그래픽이 목표라면 → RealityKit.
지금 기획(무료 + 광고 + 결제)에는 해당하지 않는다.

## 4. 사진으로 고양이 만들기는 어떻게 옮기나
지금 시안의 고양이 생성기(catmodel.js, photo2cat.js)는 웹 기술(JavaScript)로 되어 있다. Unity로 옮기는 방법:
- **고양이 모양**: 모든 고양이가 같은 크기·뼈대라, 품종 33종의 완성 모델을 앱에 넣어 두고 사진에서 **가장 가까운 품종을 고른다**. 모델을 기기에서 새로 만들 필요가 없다.
- **털 무늬와 색**: 사진에서 읽은 색과 무늬 값으로 기기 안에서 텍스처를 그린다 (무늬 그리는 코드만 Unity 셰이더로 옮김). 무늬 계산은 이미 값으로 정리되어 있어 옮기기 쉽다.
- 결과: 사진 고양이도 모든 동작과 용품을 그대로 쓴다.

## 5. 웹 시안(three.js)은 어떻게 되나
지금 `prototype/3d`의 웹 코드는 **제작 도구**로 계속 쓴다. 고양이·용품 모델, 동작 계산, 겹침 점검을 여기서 하고, 결과(FBX/glb)를 Unity로 가져간다. 게임 자체는 Unity에서 만든다.
